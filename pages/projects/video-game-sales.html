Video Game Sales Analysis

Python Data Science AI/ML
Google Colab
Role Data Scientist
Tech Stack Python, Pandas, Seaborn
ML Models Random Forest, Linear Regression
Interface Jupyter Notebook (Colab)
Status Completed

Overview

The Video Game Sales Analysis project is an exploratory data analysis (EDA) and predictive modeling pipeline built in Python. By analyzing a comprehensive dataset of over 16,000 video games, this project uncovers industry trends, genre popularity, and historical sales patterns across different regions (North America, Europe, Japan, and Global).

How I Built It

I built this pipeline within Google Colab, leveraging the standard data science ecosystem to extract insights and build predictive models:

  • Data Cleaning & Processing: Utilized pandas to import the raw CSV dataset, identify missing values, drop invalid rows, and preprocess the categorical data (like Genres and Platforms).
  • Exploratory Data Analysis (EDA): Implemented matplotlib and seaborn to visualize the distribution of game genres and calculate their total cumulative global sales. This helped identify which genres dominate the global market.
  • Dimensionality Reduction: Integrated Principal Component Analysis (PCA) from Scikit-Learn to reduce feature complexity and identify the most impactful variables driving game sales.
  • Predictive Modeling: Set up a regression pipeline using OneHotEncoder to handle categorical data and trained both Linear Regression and Random Forest Regressor models to forecast potential global sales based on historical data. Evaluated model performance using MSE, MAE, and R-squared metrics.

Features & Insights

  • Market Trend Visualization: Automatically generates bar charts outlining the most lucrative genres in the video game industry. Action and Sports genres heavily dominate the dataset.
  • Regional Analytics: Compares and contrasts sales figures from NA, EU, and JP regions against the global sum.
  • Scalable Predictive Architecture: The notebook is structured to easily swap in new datasets or more complex regression models, making it a highly reusable tool for ongoing market analysis.

Postmortem / Lessons Learned

What went well

  • Data Visualization: Using Seaborn over standard Matplotlib made the graphs look significantly more modern and readable with very little overhead.
  • Model Comparison: Pitting a standard Linear Regression model against a Random Forest Regressor provided excellent insights into how non-linear relationships in categorical data (like 'Platform' and 'Genre') impact sales predictions.

Drawbacks & Areas for Improvement

  • Dataset Limitations: The dataset used covers historical sales, heavily skewing towards older generations (like the PS2 and Wii eras). Scraping modern, live data via an API (like IGDB) would drastically improve the relevance of the predictive models for today's market.
  • Feature Engineering: Integrating review scores (e.g., Metacritic) or marketing budgets into the dataset would likely improve the R-squared score of the predictive models, as sales are heavily influenced by critical reception.
