Healthcare Chatbot

GitHub Repo
Role Developer
Tech Stack Python, Scikit-Learn, Pandas
ML Models Decision Tree, SVM
Interface Command Line Interface
Status Completed

Overview

The Healthcare Chatbot is an interactive diagnostic assistant powered by machine learning. It maps user-input symptoms to potential diseases by analyzing patterns derived from medical datasets. It operates entirely through the command line, asking users follow-up questions to narrow down the diagnosis and ultimately provide the disease name, its description, and recommended precautions to take.

How I Built It

I built the chatbot using Python and popular data science libraries to construct a predictive diagnostic pipeline:

  • Data Processing: Utilized pandas to read and parse comprehensive symptom datasets (Training.csv, Testing.csv). Engineered features by mapping strings to numerical labels using LabelEncoder.
  • Machine Learning Models: Trained a Decision Tree Classifier as the primary engine to form the logical flow of questions, and implemented an Support Vector Machine (SVM) as a secondary model to double-check predictions.
  • Dynamic Decision Traversal: Developed a custom recursive algorithm (tree_to_code) that manually traverses the trained Decision Tree. Instead of just taking a static list of symptoms, the chatbot dynamically asks the user "yes or no" questions based on the exact path of the decision tree to narrow down the probability of a specific disease.
  • Symptom Matching: Implemented regular expressions (Regex) to allow users to type symptoms naturally, which the system then matches against the known dataset database.

Features & Functionality

  • Dynamic Follow-up Questioning: The bot asks relevant questions based on your previous answers, mimicking a real doctor's diagnostic flow.
  • Severity Assessment: It calculates a severity score based on the number of days you've experienced the symptoms and advises whether an immediate doctor visit is necessary.
  • Precaution Generation: Once a diagnosis is reached, the bot fetches actionable precautions and a detailed description from the medical master database.
  • Text-to-Speech (Optional): Integrated pyttsx3 to allow the bot to vocalize its responses and diagnoses.

How to Use

Since this project is a backend machine learning system, it operates via the command line. To test it out yourself: 

# 1. Clone the repository
git clone https://github.com/Nathanieal06/Healthcare_Chatbot.git

# 2. Navigate to the directory
cd Healthcare_Chatbot

# 3. Install required dependencies
pip install -r requirements.txt
# (Make sure you have pandas, scikit-learn, numpy, and pyttsx3 installed)

# 4. Run the chatbot
python chat_bot.py

Postmortem / Lessons Learned

What went well

  • Model Integration: Successfully translating a static Scikit-Learn Decision Tree into a dynamic, interactive questionnaire was a challenging but highly rewarding puzzle. Writing the recursion to traverse the tree nodes on-the-fly made the bot feel responsive rather than just a simple static form.
  • Regex Implementation: Using regex for symptom extraction drastically improved the user experience, allowing users to type symptoms without needing to know the exact database nomenclature.

Drawbacks & Areas for Improvement

  • Command Line Interface (CLI): Currently, the project lacks a graphical user interface (GUI) or web front-end. Wrapping this Python logic into a Flask or FastAPI backend and connecting it to a sleek web chat interface would make it vastly more accessible to everyday users.
  • Hardcoded File Paths: The script relies on hardcoded paths to local CSV files (e.g., Data/Training.csv). Moving to a centralized database (like SQLite or PostgreSQL) would make the application more robust and scalable.
  • Overfitting Risks: Decision Trees are prone to overfitting to their training data if not properly pruned. While the secondary SVM helps mitigate this, implementing Cross-Validation and pruning techniques would improve real-world accuracy.
