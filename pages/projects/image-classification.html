Overview

The AI Landscape Image Classification project is an advanced computer vision model capable of categorizing satellite and aerial photography into distinct biomes. Utilizing deep learning, the model accurately scans and identifies whether an image represents a Cloudy sky, a Desert, a Green Area (Forests/Fields), or a body of Water.

How I Built It

This model was engineered entirely in Python utilizing the powerful TensorFlow and Keras libraries for Deep Learning:

  • Data Pipeline & Augmentation: Rather than relying on a static dataset, I used Keras's ImageDataGenerator to automatically rescale, rotate, shear, and flip the 5,000+ source images during training. This prevents overfitting and forces the network to learn structural patterns rather than memorizing exact pixels.
  • Deep Neural Architecture (CNN): I constructed a Convolutional Neural Network (CNN) using a Sequential API. The network features three progressively deeper convolutional blocks (32, 64, and 128 filters) combined with MaxPooling2D layers to extract intricate visual features like textures and edges.
  • Dense Layers & Dropout: The flattened feature maps are passed into a dense neural layer with 128 neurons. I implemented a Dropout(0.5) layer to arbitrarily drop 50% of connections during training, drastically improving the model's ability to generalize to new, unseen images.
  • Softmax Classification: The final layer utilizes a Softmax activation function to output a clean probability distribution across the 4 possible landscape classes.

Features & Capabilities

  • Multi-Class Landscape Detection: Seamlessly differentiates between structurally unique environments (Water vs. Desert vs. Green Area vs. Clouds).
  • GPU-Accelerated Training: The notebook is optimized for cloud GPUs (like the T4 on Google Colab) using the Adam optimizer and categorical crossentropy loss to accelerate the training epochs.
  • Visual Model Plotting: Uses Keras utilities to generate an exact flowchart visualization of the neural network's architecture directly inside the notebook.

Postmortem / Lessons Learned

What went well

  • Data Augmentation Strategy: Applying aggressive data augmentation (zooming, flipping, and shearing) proved highly effective. It made a relatively small dataset of 5,600 images feel much larger, resulting in an immediate boost to validation accuracy.
  • Network Depth Optimization: The three-layer Convolutional stack provided the perfect balance between training speed and feature extraction capability without running out of GPU memory.

Drawbacks & Areas for Improvement

  • Epoch Under-Training: The model was initially tested on only 5 epochs to gauge feasibility. To push the validation accuracy into the high 90s, the model needs to be trained for 30-50 epochs with an Early Stopping callback to halt training exactly when the loss stops improving.
  • Pre-trained Transfer Learning: Building a CNN from scratch is an excellent learning exercise, but swapping the base architecture out for a pre-trained model (like ResNet50 or MobileNetV2) using transfer learning would yield far superior accuracy on edge cases.
