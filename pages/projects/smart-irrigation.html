Smart Irrigation System

Arduino (C++) IoT / Hardware Automation
Role Hardware & Software Developer
Software Tech C++ (Arduino IDE)
Hardware Stack Arduino UNO, Soil Sensor, 5V Relay, Submersible Pump
Interface 16x2 I2C LCD Display
Status Completed

Overview

The Smart Irrigation System is a fully autonomous hardware project built with Arduino. It continuously monitors the moisture levels of the soil and automatically waters the plants when the environment becomes too dry, ensuring optimal growth without human intervention.

How I Built It

This IoT project bridges the gap between software logic and real-world mechanical action:

  • Hardware Assembly: Wired a capacitive soil moisture sensor to the analog pins of an Arduino UNO. I connected a 5V mini submersible water pump to a digital pin via a 1-Channel Relay Module to handle the voltage difference safely.
  • C++ Logic: Wrote the main control loop in C++ using the Arduino IDE. The script utilizes the analogRead() function to pull raw voltage data from the soil sensor, maps that data into a 0-100% moisture scale, and enforces strict thresholds.
  • Autonomous Automation: Programmed the system to automatically trigger the relay (turning the water pump ON) when the soil moisture drops below 30%, and turn it OFF once the moisture level safely exceeds 80%.
  • Live Interface: Integrated a 16x2 I2C LCD Display using the LiquidCrystal_I2C library to show real-time diagnostics, including the current moisture percentage and the active state of the water pump.

Features & Functionality

  • Zero Maintenance Watering: The system completely eliminates the need for manual watering schedules.
  • Water Conservation: By only watering when the soil is verifiably dry (sub 30%), the system prevents overwatering and conserves water usage.
  • Real-Time LCD Diagnostics: The integrated screen allows users to quickly glance at the health of the system without needing to plug it into a computer.

Postmortem / Lessons Learned

What went well

  • Hardware Reliability: Utilizing a relay module instead of trying to power the pump directly from the Arduino board was crucial for protecting the microcontroller from voltage spikes and ensuring stable performance.
  • I2C LCD Display: Switching to an I2C module for the LCD screen drastically reduced the required wiring from 12+ pins down to just 4, keeping the breadboard incredibly clean and easy to debug.

Drawbacks & Areas for Improvement

  • No Cloud Connectivity: While the current system works flawlessly offline, swapping the Arduino UNO for an ESP8266 or ESP32 would allow the system to connect to Wi-Fi. This would enable sending push notifications to a smartphone when the water reservoir is empty.
  • Fixed Thresholds: The code currently hardcodes the 30% and 80% thresholds. Adding a physical potentiometer to let the user manually adjust the thresholds without modifying the C++ code would greatly improve the project's usability.
